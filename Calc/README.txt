CALCULATOR FOR WINDOWS

WHAT'S INCLUDED
- calculator.py: the app source code (Python + Tkinter)
- build_exe.bat: builds a standalone Windows executable

HOW TO BUILD Calculator.exe
1. On a Windows PC, install Python 3 from https://www.python.org/downloads/windows/
   During setup, enable "Add python.exe to PATH".
2. Extract this folder somewhere on your PC.
3. Double-click build_exe.bat and wait for it to finish.
4. The executable will be created at: dist\Calculator.exe
5. You can copy Calculator.exe to another Windows PC; Python does not need to be installed there.

NOTES
- Internet is needed only the first time to install PyInstaller.
- The app itself works offline.
- Keyboard: digits and + - * /, Enter = calculate, Backspace = delete, Esc = clear.
